## Public Scope

```text
Context Diet for macOS CLI is available for macOS CLI users of Codex CLI and Claude Code CLI.
IDE, Windows native, WSL, and broad hosted/enterprise deployment are not included in this release.
```

## Authentication Note

```text
Context Diet works with normal signed-in CLI usage. API keys are optional, not mandatory. It forwards required authentication headers in memory only and does not store, print, log, or persist provider credentials.
```
