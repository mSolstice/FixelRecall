# Fixel Recall Benchmarking

Use this file for audits, benchmarks, projections, share cards and leaderboard-style reports.

## Valid comparison

- Same task
- Same repository state
- Same provider and model
- Comparable cache conditions
- Same test command
- Successful runs
- Recorded latency and usage

Compare:

1. Uncompressed control
2. Safe compressed
3. Safe compressed with exact retrieval

## Reporting

- No valid baseline means no percentage claim.
- Separate measured and estimated values.
- Label synthetic data as synthetic.
- Report positive, neutral or negative outcomes honestly.
- Never include prompts, code, repository names, paths, identities, session IDs, credentials or raw
  audit events in shareable outputs.
